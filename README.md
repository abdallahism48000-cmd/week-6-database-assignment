# Week 6 Assignment: SQL Joins and Relationships

This assignment contains SQL queries demonstrating INNER JOIN, LEFT JOIN, and RIGHT JOIN using the MySQL Classic Models database.

## Files

- `Assignment.md` - Assignment instructions and questions.
- `answer.sql` - SQL solutions for Questions 1, 2, and 3.

## Questions Covered

1. **INNER JOIN:** Retrieve employee names, email addresses, and office codes from `employees` and `offices`.
2. **LEFT JOIN:** Retrieve product names, vendors, and product lines from `products` and `productlines`.
3. **RIGHT JOIN:** Retrieve order details for the first 10 orders from `customers` and `orders`.

## Usage

Open `answer.sql` in MySQL Workbench or another SQL editor, execute the queries against the MySQL Classic Models database, and review the returned results.
